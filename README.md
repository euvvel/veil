# veil

> *Oh could I raise the darken'd veil…* (Nathaniel Hawthorne)

A personal Soulseek client driven from Telegram. Search from a mini app, and the track crosses over into your Telegram chat. Nothing is kept: no audio, no files, only a line of text recording that it happened.

For two people only, on an allowlist.
